## 二、响应质量 — 80/100

### 2.1 优势

- **检索质量质变**: BM25 的 IDF 在作用域内统计 bigram 文档频率, 罕见词高分; 时间衰减改乘性 `s = bm*10*(0.4+0.6*recency)`, 100天前旧记忆不再压过新记忆
- **scope 隔离**: 支持多租户检索, AML 治理维度直接受益
- **工具错误自愈**: 工具调用失败后, 汇总错误喂回模型修正重试 (最多2次), 不是简单报错放弃
- **上下文压缩**: LLM 真摘要 (非堆叠), 超长工具结果裁剪保留头尾, 会话历史按 token 预算裁剪
- **引用规则**: system prompt 内置 CITATION_RULE, 要求引用 web_search/http_request 来源
- **本地意图预判**: 高置信简单指令 (问候/时间/记忆查询) 本地处理, 不调 LLM, 省成本更快

### 2.2 不足

- **openclaw/dsh 后端不支持工具调用**: 这两个引擎的 `apiChat` 返回 `tool_calls: null`, 意味着使用 openclaw 或 dsh 作为底座时, agent 无法自主调用工具, 仅 http 后端支持完整工具循环
- **openclaw/dsh 不支持流式**: `streamChat` 对这两个后端是一次性返回全文, 伪流式
- **会话历史裁剪策略粗糙**: `MAX_SESSION_HISTORY = 20` 条硬截断 + token 预算, 无语义保留策略 (可能裁掉重要上下文)
- **记忆提取无 LLM 主动提炼**: 对话中的关键信息仅靠 `addMemory` 启发式 (长度>4 + 非寒暄) 判断, 无信息量评估

## 四、处理效率 — 82/100

### 4.1 优势

- **零依赖**: 整个项目无任何 npm 依赖, 启动快, 无供应链风险
- **事件溯源消除重复写入**: v0.5 之前 l0/today/facts 三处各写一遍, v0.6 收敛到 session 事件日志唯一事实源
- **倒排索引**: 检索从 O(n) 全遍历优化到 O(候选), 候选集过大时自动回退全量保证召回
- **BM25 统计缓存**: `_queryStats` 按 scope 缓存 df/avgdl, facts 不可变, add 时 `clear()` 失效
- **并发健康探测**: 多 provider 时 `Promise.all` 并发 health(), 避免串行等待 180s 超时 (最坏15分钟→秒级)
- **工具结果裁剪**: 超过 4000 字符的工具结果自动裁剪保留头尾, 防撑爆上下文
- **原子写**: `atomicWrite` 先写 tmp 再 rename, Windows 并发写 EPERM 时降级直写

### 4.2 不足

- **openclaw 后端同步阻塞已改异步**: v0.4 用 `execFileSync` (阻塞事件循环), v0.5 已改为 `spawn` 异步, 但仍有改进空间
- **会话日志全量重写**: `_flush` 每次追加事件后重写整个 JSONL 文件, 大会话 (1000+条) 时写放大严重
- **_queryStats 首次查询 O(N)**: 缓存命中后 0 次重算, 但首次查询或 cache 失效后仍需全量扫描
- **corrupt 备份清理仅在启动时**: 运行期间不清理, 长期运行可能积累
- **军团通信无消息队列**: `send` 直接写 stdin, 无背压/缓冲机制

## 五、用户体验 — 78/100

### 5.1 优势

- **主题跟随系统**: `prefers-color-scheme` 深浅两套 CSS 变量, 自动适配
- **移动端响应式**: 窄屏 (<=768px) 侧栏变抽屉, 右上角"面板"按钮切换
- **人格鲜明**: "兄弟的个人助手", "像一个强盗, 看到有用的技能就抢过来", 交互有温度

## 七、改进建议 (按优先级)

### P0 — 立即修复

1. **openclaw/dsh 后端补齐工具调用**: 当前这两个后端 `apiChat` 返回 `tool_calls: null`, 导致使用非 http 后座时 agent 丧失工具能力。需解析引擎输出的工具调用意图, 或在 agent 层做工具调用代理
2. **清理 dead code**: 删除 `_queryJaccard`/`_tokenize`/`_jaccard` 旧检索路径, 减少认知负担
3. **提交未版本控制文件**: 30+ 文件未 commit, 需分批提交并更新 CHANGELOG
4. **hardcoded 路径外部化**: `DEFAULT_DSH_ROOT` / `DEFAULT_MJS` 改为环境变量或配置项

### P1 — 本周完成

5. **会话日志追加写优化**: `_flush` 从全量重写改为 `fs.appendFileSync`, 消除大会话写放大
6. **Web UI 多会话管理**: 支持创建/切换/删除/重命名会话, 列表展示
7. **工具调用过程可视化**: Web UI 展示 agent 正在调用哪个工具、参数、耗时
8. **notify 工具描述中文化**: 统一工具描述语言
9. **记忆主动提炼**: 对高信息量对话用 LLM 做结构化提炼, 替代简单启发式
10. **AML 适配器限流**: 对齐 http.js 的 1MB/60rpm

### P2 — 中期演进

11. **多模态接入**: 图片理解 / OCR / 向量嵌入
12. **MCP 协议支持**: 接入 MCP 生态, 替代独立 AML 适配器
13. **向量检索**: BM25 + 向量混合检索, 提升语义匹配
14. **CI/CD 流水线**: GitHub Actions 跑测试 + 代码覆盖率
15. **飞书/微信通道实现**: 或明确标记为不支持, 避免用户困惑
16. **会话历史语义保留**: 裁剪时保留高信息量消息, 非简单条数截断
17. **代码覆盖率报告**: `node --test --experimental-test-coverage`

### P3 — 长期方向

18. **插件市场**: 工具/Skill 可独立安装卸载, 社区贡献
19. **多 Agent 协作编排**: 军团从简单 broadcast/dispatch 升级为 DAG 任务编排
